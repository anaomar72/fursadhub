# FursadHub web

React + TypeScript + Vite frontend for FursadHub. See the [repository root README](../../README.md) for local setup and the full stack overview, and [`docs/architecture/REPOSITORY_STRUCTURE.md`](../../docs/architecture/REPOSITORY_STRUCTURE.md) for the source layout.

```bash
npm ci
npm run dev        # http://localhost:5173
npm run lint
npm run typecheck
npm run test
npm run build
```
